## [File Triage Tool]( https://github.com/samgarfoot/Coding-Projects/tree/main/File-Triage-Tool)

A security automation tool designed to simulate lightweight endpoint file monitoring and triage workflows used in SOC environments.

The tool recursively scans directories, classifies files by type, generates SHA-256 hashes for forensic tracking, detects potentially suspicious executables, and quarantines risky files into isolated folders.

### Key Concepts Demonstrated
- File system monitoring
- Threat detection logic
- Hash-based file analysis
- Security logging & audit trails
- Quarantine workflows
- Cross-platform file handling

### Features
- Recursive directory scanning
- Automatic file classification
- SHA-256 hash generation
- Suspicious file detection (`.exe`, `.bat`)
- Quarantine system
- Structured event logging
- Windows, Linux, and macOS support
